002

D.A.N
Do Anything Now

A personal AI chat app with streaming replies, image input and a hands-free call mode — tap once and it listens, answers, speaks, then listens again. Voice input runs through Whisper rather than the browser’s speech API, which has to be told the language upfront; Whisper reads it from the audio instead. Call mode turned on one non-obvious fix: audio.play() resolves when playback starts, not ends, so it waits on the ended event or it would start listening mid-sentence. Vanilla JS, no framework, no build step, and the API key never leaves the server.

003

DanTech
IT Helpdesk Agent

A LangGraph agent that triages IT tickets the way a Tier 1 technician does. The point is the routing, not the chat: severity picks the first branch, retrieval confidence picks the second, and a weak vector match escalates to a human rather than letting the model improvise from irrelevant context. The 0.44 threshold was calibrated against labelled data, not guessed — it routes 23 of 23 cases where the 0.5 it replaced managed 22. Two eval harnesses, and the classifier’s two failures left in the README as markers rather than relabelled to flatter the score.
